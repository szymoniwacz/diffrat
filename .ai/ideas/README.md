# Ideas

## Purpose

This folder stores project ideas before they become implementation work.

## Structure

```txt
.ai/ideas/
  active/
  expanded/
  implemented/
  archived/
```

## Workflow

1. Add a rough idea to `active/`.
2. Expand it into problem, goal, scope, risks, and open questions.
3. Move it to `expanded/` when it is ready for planning.
4. Move it to `implemented/` after completion.
5. Move it to `archived/` if rejected or deferred.
