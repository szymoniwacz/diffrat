# Documentation Instructions

Canonical instructions for edits under `.ai/`.

## Purpose

The `.ai/` folder is the source of truth for AI-assisted project work. Treat edits here as authoritative documentation changes.

## Before editing

1. Read `.ai/README.md` to understand folder responsibilities.
2. Check whether the content already exists elsewhere. Do not duplicate rules across files.
3. Keep one file, one clear responsibility.
4. Review `.ai/conventions/documentation-rules.md` for documentation standards.

## Editing rules

- Preserve existing structure unless a task explicitly requires change.
- Write concise, actionable documentation.
- Point tool-specific adapters to `.ai/` instead of copying full procedures.
- Update cross-references when moving or renaming concepts.

## What to avoid

- Duplicating content from canonical instructions in `.ai/instructions/` or tool-specific adapters.
- Adding implementation code to `.ai/`.
- Broad rewrites without a scoped task and review plan.

## After editing

Verify the change stays consistent with `.ai/docs/template-flow.md` and related docs.
