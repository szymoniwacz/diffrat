# Golden Flow Examples

## Purpose

These examples show what good AI-assisted work looks like in practice.

They are process-focused demonstrations—not application code to copy.

## How to use

1. Read an example for the task type you are doing.
2. Compare your task packet, plan, and review output to the example structure.
3. Adapt the pattern to your project; do not copy product-specific content.

## What good looks like

- context read before implementation
- explicit goal, scope, and non-goals
- ready for planning before plan creation
- implementation-ready before file changes
- small plan with validation
- scoped diff and review packet or PR description
- no unrelated cleanup
